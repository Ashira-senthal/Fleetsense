# `outputs/` schema — FleetSense

_Generated by `python -m src.schema`. Do not edit by hand: change `src/schema.py` and re-run, so the validator and this document cannot disagree._

Data provenance: **porto_taxi_uci339**, synthetic: **False**. Limitation: taxis, not buses: no fixed stops, no timetable, no schedule delay

All coordinates are WGS84 degrees. `NaN`/empty means *not defined for that row* (for example Davies–Bouldin for a precomputed distance matrix), never zero.

| `n_cells` | int | H3 cells | Cells in the cluster. |
| `share_cells` | float | fraction 0-1 | Share of all clustered cells. |
| `n_visits` | float | distinct trips per cell | Mean over the cluster's cells. |
| `n_vehicles` | float | vehicles per cell | Mean over the cluster's cells. |
| `dwell_s_per_visit` | float | seconds | Mean below-5 km/h time per visit. |
| `speed_mean` | float | km/h | Mean of valid step speeds. |
| `speed_p95` | float | km/h | 95th percentile of valid step speeds. |
| `speed_cv` | float | ratio sd/mean | Stop-and-go signature; higher = more accelerate/brake cycling. |
| `slow_share` | float | fraction 0-1 | Share of valid steps below 12 km/h. |
| `night_share` | float | fraction 0-1 | Share of pings in 00:00-05:59. |

## `cluster_pois.csv`

OpenStreetMap POI counts per cluster, absolute and per cell. Per-cell density is the comparable number (cluster area differs).

* format: `csv`  ·  key: `cluster`

| column | dtype | unit | meaning |
|---|---|---|---|
| `cluster` | int | id | Cluster id. |
| `poi_total` | float | POIs | All POIs in the cluster's cells. |
| `poi_per_cell` | float | POIs per cell | poi_total / n_cells. |
| `<category>_total` | float | POIs | POIs of that category in the cluster. |
| `<category>_per_cell` | float | POIs per cell | Total / n_cells. |

Pattern-matched columns:

* `^[a-z_]+_total$` → float, POIs. Category total.
* `^[a-z_]+_per_cell$` → float, POIs per cell. Category density.

Categories: `education`, `market`, `transport`, `health`, `hospitality`, `civic`, `worship`, `retail_area`, `industry`

## `cluster_hourly_profile.parquet`

Cluster x hour-of-week activity matrix: what the dashboard's weekly chart needs, one row per cluster, no aggregation left to do in the app.

* format: `parquet`  ·  key: `cluster (index)`

168 columns `0`–`167`, dtype `float`, unit **mean pings per cell per hour**: Column j = hour-of-week j, where j = weekday*24 + hour and j = 0 is Monday 00:00. Averaged over the cluster's cells, so clusters of different size are comparable.

## `day_anomalies.csv`

One row per calendar day: sampled trip count, median speed, the dispersion-corrected z-scores and the flags. Days with too few sampled trips are marked 'not assessable' in `note`.

* format: `csv`  ·  key: `date`

| column | dtype | unit | meaning |
|---|---|---|---|
| `date` | str | ISO date | Calendar day (YYYY-MM-DD). |
| `n_trips` | int | trips | Sampled trips starting that day (NOT a city total). |
| `median_speed` | float | km/h | Median trip mean speed that day. |
| `median_duration` | float | seconds | Median trip duration that day. |
| `poisson_z` | float | z | Raw (n - mu)/sqrt(mu) against the same weekday. |
| `dispersion_phi` | float | ratio | Estimated over-dispersion, same value on every row (~3.2 here). |
| `volume_z` | float | z | Poisson z scaled by sqrt(phi); the one to use. |
| `speed_robust_z` | float | robust z | Median speed vs all days. |
| `is_anomaly_volume` | bool | flag | |volume_z| >= 2.5 with >= 30 trips. |
| `is_anomaly_speed` | bool | flag | |speed_robust_z| >= 2.5 with >= 30 trips (either direction). |
| `speed_direction` | str | enum | slower | faster | empty when not flagged. |
| `note` | str | - | Why a day was not assessed, else empty. |
